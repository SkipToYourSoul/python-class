# 首页与课程目录规范

仅修改首页、目录或共享入口时读取。本文补充 [AGENTS.md](../AGENTS.md)，不约束其他系列课件；视觉参考和历史记录不覆盖用户当前要求。

### 共享要求

- 全站入口复用 `CourseNavigation`；首页与目录导航统一无衬线字体及排版，不加首页专属覆盖。目录标题和正文沿用课件的无衬线字体，首页路线图与徽章使用衬线字体，英文标签使用等宽字体。
- 入口共用排版、间距、边框和操作反馈，配色与装饰按系列隔离。Python 首页与 AI with Python 使用纸色、深蓝、蓝黄和图鉴徽章，不将其推广为其他系列主题。
- 普通卡片使用 **2px 边框**，不设常驻错位阴影；交互元素仅在悬停、聚焦或选中时显示错位阴影。首页装饰例外见下文。动效短促并尊重减少动态效果设置。

### Python 首页

- 视觉以 [Paper Atlas 参考图](../design-reviews/course-home-reference.png) 为准，保留装裱框、纸张细网格、淡色阶段编号、双圈徽章、黄色完成印章、弧形虚线和底部罗盘；允许参考图中的图框柔影、多层圆环与按钮错位阴影。
- 采用包含顶部导航的 **16:9 单屏舞台**，完整适配视口、空余留边，不依赖滚动；课程名称、简介、状态和操作文字至少 18px。小窗口容不下可读路线时提供宽屏提示及课程入口，不改成纵向徽章长页。
- 中央直接使用用户原始完整路线图，保留内容、比例与颜色，和外围徽章留出安全距离；支持弹窗、原图尺寸查看、关闭、Escape 与焦点返回。
- 保留 **01 → 02 → 03** 路线和三个同风格淡色背景编号；虚线以原有弧线从圆形徽章背后贯穿。小派沿虚线及图框左、上边缘形成闭环，遮挡关系合理且不覆盖文字；自动循环、不设播放控件，减少动态效果或页面隐藏时停止。
- 徽章保留编号、中文阶段和英文课名；完成印章跨圆形底边、完成文字在圆外；当前阶段用蓝色圆章与黄色标签，徽章和进入按钮共用一个链接及反馈。装饰层次不得遮挡原图内容。

### AI with Python 目录

- 结构固定为 **第 01 课导入 → 数据（02–06 课）→ 模型（07–11 课）→ 第 12 课挑战**，仅数据和模型标为学习阶段。顶部紧凑路线导航支持鼠标与键盘定位四区，提供目标提示，不伪造个人学习进度。
- 导入、挑战使用独立横向卡片；两大学习阶段各列五课，标题含名称、课次和一句目标，第 06、11 课标“阶段作品”。桌面两栏对应行对齐，窄屏按导入、数据、模型、挑战自然滚动，不套用首页固定比例。
- 阶段与课程统一来自 `lib/course-data.ts`；完整显示课名与精简简介，长课名可分故事标题和专业主题，短课名不强加副标题。常见电脑首屏展示课程介绍、路线导航和导入课程。
- 可学习课程整卡可点击，状态为“进入学习 →”；未开放课程标“准备中”，与首页“已学完”区分。
