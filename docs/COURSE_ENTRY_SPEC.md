# 首页与课程目录规范

仅修改首页、目录或共享入口时读取。本文维护站点入口的产品要求及验收标准；项目协作和工程流程见 [AGENTS.md](../AGENTS.md)，课件教学与设计要求见 [课程设计规范](../COURSE_DESIGN_SYSTEM.md)。本文不约束其他系列课件；视觉参考和历史记录不覆盖用户当前要求。

### 课程入口共享要求

- 课程入口复用 `CourseNavigation`，品牌与“全部课程”默认返回 `/python`；Python 首页与目录导航统一使用无衬线字体；通过共享组件的 `appearance` 参数切换纸色或深蓝外观，不在单页覆盖共享导航。目录标题和正文沿用课件的无衬线字体，首页主标题、阶段名称及英文课名使用衬线字体，英文眉题使用等宽字体。
- 入口共用排版、间距、边框和操作反馈，配色与装饰按系列隔离。Python 首页与 AI with Python 使用纸色、深蓝、蓝黄和图鉴徽章，不将其推广为其他系列主题。
- 普通卡片使用 **2px 边框**，不设常驻错位阴影；交互元素仅在悬停、聚焦或选中时显示错位阴影。首页装饰例外见下文。动效短促并尊重减少动态效果设置。

### 个人主页 `/`

- 根入口为李美丽（李叶）的个人主页，正式实现位于 `app/page.tsx`。视觉与交互以用户提供的视频「个人主页设计参考.mp4」和当前明确要求为准；`public/personal-home/index.html` 仅作为内容原型，旧样式与本文默认值不覆盖当前要求。
- 还原视频的白色背景、居中竖版纸张海报、三章荧光色、底部波形刻度尺与揉纸展开转场。三章标题依次为「我的作品」「从作品到分享」「让孩子成为创作者」，英文标签依次为「RED WORLD」「BUILD&REFINE」「AI WITH PYTHON」，第二章海报英文大标题同为「BUILD&REFINE」，对应作品与获奖、分享与教学、儿童编程课堂，保留真实图片与主要事实。三章黑色标签依次为「黑客松金奖」「官方课程讲师」「AI 编程创作课」，配文依次为「用 36 小时，把一个想法做成世界」「把做作品的方法，分享给更多人」「把脑海里的想法，做成自己的作品」。
- 左上显示用户提供的纸艺个人形象和「李美丽」，名字上方增加小号暖灰色「你好，我是」，与姓名左对齐，不设底色或边框；桌面与手机均保留该问候，短屏通过紧凑间距保持完整同屏。姓名使用基于得意黑的本地精简字体「Meili Display」，保持黑色与轻微斜势，仅用于姓名；浏览器图标使用同一形象，首页 Title 为「李美丽 · Builder & AI Coach」；手机头像与名字、身份并排安排，采用紧凑间距控制信息区高度。使用同一手写字体、基线及章节配色的「Builder / AI Coach」双身份，AI Coach 字号为 Builder 的 78%，桌面与移动端保持一致，简介统一为两行：「在小红书写代码，」「陪孩子用 AI 把想法做成作品。」；简介不使用 emoji，两行字号与字重一致；右上统一为联系方式，提供等宽对齐的「小红书主页」「微信联系」入口；桌面悬停展示用户提供的小红书主页截图／微信二维码，键盘可操作、Escape 可关闭，手机点击展开并支持关闭或点击外部收起。小红书卡片保留打开原主页的链接。课程入口保留在第三章海报内，指向 `/python`。「Builder / AI Coach」颜色随当前章节海报主色变化；绿色章节身份字使用较深的同色系实心绿，保证白底可读并保持字形一致。
- 三章海报底部各保留两项信息，双列同一行显示，桌面与移动端一致：第一章「36h Solo Coding」「50万元奖金」；第二章「2 节作品实战课」「单期 1670+ 赞」；第三章「Python 编程实战」「用 AI 做出自己的作品」。
- 第三章主页文案不限定课程总节数；介绍使用「适合小学生的 AI 编程实战课」，页脚使用「CREATE WITH PYTHON / BUILD WITH AI」。
- 第三章下方课程介绍与两项核心信息统一使用暖白色 `#f3f0ff`，桌面与移动端一致；大标题、顶部编号保留深色；课程入口使用透明底、暖白文字与细下划线，和介绍左对齐、宽度随文案收缩，悬停或键盘聚焦时下划线加深、箭头轻移，触屏点击区域至少 44px 高。
- 三章正文、核心信息使用统一字号与字重层级，段内行距及段间节奏一致；第三章为课程按钮预留独立区域。正文、分隔线、核心信息及按钮沿统一内边距对齐。手机短屏通过压缩非必要留白、放大正文与页脚改善阅读，保留全部文案；正文区纸纹弱化，边缘与标题区保留纸张质感。
- 揉纸转场采用边角先卷、中心后收的主次不规则折痕、米白纸背与淡透印、薄边和哑光光影；收拢至压紧阶段保留当前海报的主色与印刷内容，开始展开时切换为下一张海报；压紧时以印刷正面为主，不统一漂白为米白色，阴影随压缩与朝向收窄。压紧末段边角向内包裹为紧实的不规则纸团，使用有棱角的折面与凹陷，避免停留在张开的翼状轮廓或光滑球体。展开时主体先释放、边角轻微回稳。桌面约 1 秒、手机约 0.9 秒；拖动跨中点、反向与中途接管沿同一轨迹连续，松手保留当前朝向。手机降低细褶皱、网格与渲染分辨率，保持操作方式和同屏布局。
- 操作箭头统一使用 SVG，包括右上入口、唱片把手和课程操作；不使用会在 iPhone 上渲染成 emoji 的箭头字符。
- 移动端按动态视口高度与设备安全区排版，名字、Builder / AI Coach 身份、两行简介、海报、刻度尺、章节标签及全部操作在一个实际可视屏幕内完整显示。标准手机独立重排海报，710px 以下短屏把英文标题收为一行，日期／期次放在海报底部；不丢失主要信息。横屏提供侧栏布局，不让浏览器栏遮挡底部。
- 海报照片叠放，三章均不展示照片下方的标题；照片组右下方使用「叠片图标＋张数」的轻量提示，无底色、边框与阴影，桌面悬停主照片轻微上浮、提示加深，手机常驻张数。照片保留原始比例，按接近的视觉面积排布；间距按整组旋转后相纸的外边缘计算，为副标题、张数行、键盘焦点和正文分别预留空间，短屏也不贴边或重叠。在这些安全间距内尽量放大主照片，背后照片适当收小、保留露角，不挤压文案、张数行或键盘焦点。张数提示常态保持足够对比度。整组照片点击打开当前章节画廊：完整大图、全部缩略图、上一张／下一张、位置计数与说明；支持键盘和触屏切图；提供明确的放大入口、双击／双点放大，支持双指、滚轮、按钮缩放、适应屏幕和拖动，缩放限制为适应尺寸的 100%–600%，平移不超出图片边界。Escape 先退出放大回到同一张照片，再关闭画廊并返回首页焦点。第二章共 4 图，以课程封面为首图，包含讲师介绍、PK 海报与天团合影；照片区域不显示大矩形焦点黑框，键盘焦点仅在照片张数提示周围清晰标示。第三章共 6 图，以秋季班结课合影为首图，保留课程定位、讲师个人资质证书和其余课堂／学生作品照片，不重复使用第二章课程封面。
- 保留点击海报非照片／课程按钮区域切到下一章；照片区域打开画廊，课程按钮进入学习路线，滑动不得误触这三个点击操作。支持拖动刻度尺、章节按钮、键盘及触屏切换；尊重减少动态效果设置，隐藏章节不进入键盘焦点顺序。不自动播放，不设底部播放控件或快捷链接；个人主页上的全部课程入口统一进入 `/python` 学习路线，第三章海报内按钮为「开启我的创作之旅」。触摸或鼠标操作刻度尺不显示焦点黑框，键盘操作仍保留清晰的焦点提示。

- 课程介绍明确面向小学生，学习目标为认识 Python 的能力、借助 AI 做出自己的编程作品，不承诺学完掌握全部技能。奖金文案显示「50万元奖金」，事实口径为李美丽个人获奖奖金；IITC 工信人才认证为讲师个人资质，不表述为学生结课所得认证。

### Python 首页 `/python`

- 旧群岛首页保留于 `/python`，实现位于 `app/python/page.tsx`；该页 `CourseNavigation` 的 `homeHref` 指向 `/python`。视觉以用户选定的 [探索群岛设计稿](../design-reviews/course-home-reference.png) 为准：纸色细网格、云雾远山、三座立体浮岛和递进的蓝色点状路线，保留大衬线标题、阶段编号、黄色完成标记及底部罗盘。正式插画与 HTML 文字、操作分离，不以整页设计稿充当可交互网页。
- 采用包含顶部导航的 **16:9 单屏舞台**，完整适配视口、空余留边，不依赖滚动；课程名称、简介、状态和操作文字至少 18px。小窗口容不下可读路线时提供宽屏提示及课程入口，不改成纵向长页。
- 保留 **01 基础 → 02 进阶 → 03 实践** 三阶段；阶段说明依次为「看懂 Python 代码」「掌握编程思维」「探索编程的可能，学会与 AI 协作」。前两阶段标「已学完」，实践阶段仅保留「进入课程」按钮，不显示「当前阶段」标签。
- 原始完整路线图由「查看完整路线图」按钮触发展示，不占据主页中央；弹窗保留原图内容、比例与颜色，支持原图尺寸查看、关闭、Escape 与焦点返回。
- 三座浮岛、连接线与课程信息保持设计稿的位置关系，插画及装饰不遮挡文字或操作；不再保留旧版中央画框、环形徽章和小派绕框动画。

### AI with Python 目录

- 结构固定为 **第 01 课导入 → 数据（02–06 课）→ 模型（07–11 课）→ 第 12 课挑战**，仅数据和模型标为学习阶段。顶部紧凑路线导航支持鼠标与键盘定位四区，提供目标提示，不伪造个人学习进度。
- 导入、挑战使用独立横向卡片；两大学习阶段各列五课，标题含名称、课次和一句目标，第 06、11 课标“阶段作品”。桌面两栏对应行对齐，窄屏按导入、数据、模型、挑战自然滚动，不套用首页固定比例。
- 阶段与课程统一来自 `lib/course-data.ts`；完整显示课名与精简简介，长课名可分故事标题和专业主题，短课名不强加副标题。常见电脑首屏展示课程介绍、路线导航和导入课程。
- 可学习课程整卡可点击，状态为“进入学习 →”；未开放课程标“准备中”，与首页“已学完”区分。

## 入口验收标准

- 桌面沿用 [课程验收标准](../COURSE_DESIGN_SYSTEM.md#课程验收标准) 中的三种视口尺寸及 100% 缩放要求，检查受影响入口及适用的初始、悬停、聚焦、选中和弹窗状态；文字、图片、浮层、阴影及焦点轮廓无重叠裁切。
- 另查窄屏无横向溢出、阶段定位、键盘聚焦、图片弹窗和往返链接；个人主页检查三章切换、拖动与课程链接，Python 首页窄屏提示与目录自然滚动分别遵循本文对应要求。
- 共享组件变更覆盖受影响入口与页面类型；结合截图与实际操作验证。构建、代码检查及交付流程按 AGENTS.md 执行。
