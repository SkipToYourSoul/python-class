# 第五课：勇闯图表世界

## 本课内容

42 个逐页演示场景，沿用公共课程播放器、章节封面、JupyterLab 代码面板、小派讲解和课堂练习印章。

- 第一小节：课前快问快答唤起生活中的图表经验；用新侦察档案比较五个个体的身高，衔接第四课的数值／分类数据。通过前九个速度解释集中趋势和离散趋势，再分组计数、生成直方图。单独用同年龄人群的身高示意讲解正态分布，回到全部恶魔数据检验分布。课堂练习 01 用一页展示完整跟写代码、对应直方图及可展开的练习收获，说明多数个体所在的速度范围、最高区间及两端较少的特点。旧链接 `l5-practice-01-code` 映射到合并页 `l5-practice-01`。
- 第二小节：先猜身高与速度的关系，再把一行记录映射为一个点，用全部个体检验猜想。依次讲解散点图、折线图与条形图的概念、用途和代码，再演示颜色、点面积及分组表达更多变量。课堂练习 02 复用讲解中的三个例子：90 个体的身高与速度用散点图、D001 的六次巡逻速度用折线图、三族各 30 个体的平均速度用条形图。跟写页 `l5-practice-02` 同时展示共用准备和三段绘图代码，不需切换；核对页 `l5-practice-02-results` 并排展示三图与观察问题，可一起展开收获，下方漫画让勇士汇总三条线索，为最终决战准备。两页沿用课堂练习 02，旧链接 `l5-practice-02-code` 仍映射到跟写页。
- 第三小节：承接已认识的种类颜色，用代码实现着色、换一组特征继续观察。课堂练习 03 完成恶魔图鉴，并在剧情中交给勇士。
- 结课挑战：研究真实企鹅的四项数值特征，自主选轴、按种类着色、记录发现与证据、保存观察报告。已知种类用于观察差异，不涉及训练分类模型。

承接第四课“魔王现身，城堡守住了”。第五课新增个体观测档案，不能把第四课的整场进攻威胁值当作个体属性。研究身高、速度、体重，保持单位与观测口径清楚。

## 数据与练习

`study-data.ts` 由 `scripts/build-lesson05-practice.py` 根据练习 CSV 生成。网页与 Python 使用同一份观测。

- 恶魔：90 个教学模拟个体，三个种类各 30 个，保留类内差异、类别重叠和高个体快速度的例外。
- 时间序列：D001 在 8—18 时每两小时一次，共六次速度观测。
- 第 28 页承接同一时间序列：保留 D001，再补入藤甲魔族 D002 与冰翼魔族 D009 的同期观测，共 18 条教学模拟记录。颜色表示种类，每族仅观测一个体，不能视作全族的平均表现；网页与新增 `patrol-by-kind.csv` 使用同一数据。
- 企鹅：Palmer Penguins 原始 344 行，仅删除四个数值字段中存在缺失的两行，保留 342 条原始测量。原始 CSV、来源与许可随包提供。

直方图采用 seaborn 默认自动分组；网页的区间与数量由 Python 生成，使用同一份数据与 NumPy auto 方法。课堂分组演示使用前九个个体、三个等宽区间（4–8、8–12、12–16 m/s），目的是解释柱高与数量的关系。全体直方图改用自动分组，刻度标明为近似值。

投屏与复制代码统一取自 `practice-content.ts`；Python 包生成程序也读取这些常量。字体配置在笔记本开头预置，学生先运行再跟写。网页图表是数据演示，Python 在 JupyterLab 中运行。

练习文件位于 `public/courses/ai-with-python/lesson-05/practice/`，入口为 `lesson-05-practice.zip`。说明、单位、数据处理和来源详见练习目录 README。

## 交互与状态

课堂页使用公共 `usePageState`，翻页和刷新保留选择、揭晓与输入；公共菜单区分重置本页和重新开始本课。

图表选择题保留原题、所选答案和依据，可改选重试。开放观察不自动判分。改变研究坐标后，需要重新核对自查项。

企鹅挑战的 Python 参考与下载代码跟随当前横轴、纵轴和着色状态；坐标标签同步单位。
