# 第六课：决战魔王

数据阶段综合练习。剧情从三塔供能展开：战前准备 → 三队部署 → 攻破全部魔塔 → 三队会合挑战魔王。三个小节、三个课堂练习、一个结课挑战，共 35 屏。练习包保留三个简短课后填空。

## 三节内容

1. **战前作战准备**：读懂三塔情报；真实 HTTP 获取网页，用 BeautifulSoup 提取整份 CSV 正文并写入 `towers.csv`。36 条记录、8 列，三塔各 12 个时刻（6—17 时），每行包含当班守卫。
2. **部署三队作战策略**：延续第四课方法：望看懂类型与行列，闻用 Python 读取检查，切分组、统计、排序与筛选；问贯穿追问依据。比较各塔外罩、防御均值，筛选外罩低于 30 的记录，再比较守卫防御、查明属性与弱点，部署三队。
3. **用图表攻破三塔**：两图分工 → 折线圈出每塔两个可破罩时段 → 北塔双指标冲突 → 学写两种绘图代码 → 逐塔在散点图上读坐标、比较防御、查弱点并说明方案 → 同屏完整代码填空 → 阵前核验并逐塔出击。图表中的时刻、坐标、候选表与方案共用原始记录，既保留历史证据，也明确阵前新读数。

课后练习分别考查 `requests/csv/write`、`groupby/energy/30`、`hour/energy/hue`，每题三个空，同屏显示，原答案与逐空反馈保留，可修改重试。

课堂练习一集中在第12页，8 个代码填空覆盖导入、获取、解析、定位、提取和写入。核对后保留原填答，可逐空修改、重试和复制当前代码，再到 Notebook 运行并检查 `towers.csv`。原第13页重复的三空练习已删除，第12页后直接进入第二节；课后练习一只保留在练习包中。旧完整代码页和课后三空页链接自动转向第12页。

课堂练习二集中在第20页，原入口、完整代码页和三空页合并。左右两栏同时展示读取检查与分组筛选的完整代码，8空覆盖 `read_csv/head/info/groupby/mean/count/energy/sort_values`；填满后与完整参考逐字一致。状态保留、逐空核对、重试、复制与课堂一一致。课后练习二保留在练习包；旧链接转到课堂练习二。

课堂练习三也采用完整代码同屏双栏填空，8空覆盖 `read_csv/lineplot/hour/energy/hue/scatterplot/defense/savefig`。读入自己保存的CSV，绘制并保存折线与散点图；核对虚线下的同塔观测点，回表解释时刻与装备。填空答案、复制内容、Notebook与完整参考共用源字符串，支持逐空反馈、修改重试和状态保留。

第二节第14页漫画按原生横向比例展示，去掉灰色填充。第15页明确分类数据与数值数据，分类卡和第19页三队卡都使用淡化漫画背景。第16页按 `head()`、`info()`、`dtypes` 分步展示：前5条完整8列、36行8列整体信息及每列类型，输出来自真实样本执行生成的 `analysis-evidence.json`。文本类型随Pandas版本可显示 `str` 或 `object`，不能把 `dtypes` 输出末尾的Series类型误当作数据列类型。第16、17页漫画分别推进档案验收、分组比较剧情。

## 数据、策略与剧情门槛

`study-data.ts` 是网页、课件、Python 材料、图表与战斗的共用证据源。外罩严格低于 30 才能突破；之后比较守卫防御并按弱点选择装备。三座不同的塔都完成，才解锁魔王，重播同塔不累计进度。“切断供能，直面魔王”剧情页也读取同一进度：未完成时显示已破数量和返回战役入口，全部完成才展示魔王现身；重置后立即重新锁定。

- 北塔炎角兽族：强光；历史计划 11 时，外罩 25、防御 30。10 时外罩虽更低（18），防御却更高（42），不能只看外罩最小值。
- 东塔藤甲魔族：火焰；历史计划 14 时，外罩 22、防御 34。
- 西塔冰翼魔族：热量；历史计划 17 时，外罩 19、防御 25。

历史记录用于计划；阵前观测核对当前行动，不能以历史读数冒充现场证据。阵前北、东、西塔外罩/防御分别为 21/32、24/35、22/28。每名当班守卫有唯一编号，统计每塔 `guard.count` 得到 12 条，不重复计数同一守卫。

## 魔王综合挑战

三塔熄灭漫画后，重新获取九个护甲部位的网页，保存 `boss.csv`，筛选外罩低于 30 的候选，按防御排序并画散点图（横轴防御、纵轴外罩、颜色为弱点，点旁标部位）。最优突破口为胸甲：外罩 18、防御 24、弱点火焰。塔的数据不能代替魔王的数据。

## 代码、交互与素材

`practice-content.ts` 的字符串共用于页面、复制、Notebook、完整参考和 ZIP；所有课堂练习与最终准备的完整代码同屏展示。第7页及课堂练习一明确写出 `url = "https://www.creaai.online/battle-towers.html"`。解压整个练习包，打开 Notebook，先运行字体与备用本机站环境格，再亲自跟写。离线时可用环境格打印的本机地址替换练习一的 url 行；魔王挑战沿用本机站。无需天气 API 或新增 Python 库。Python 在 JupyterLab 执行，网页展示同源结果供核对。

漫画提示词记录在 `assets/prompts.md`。侦察、请求网页和提取正文页分别加入 `station-observation.png`、`fetch-message.png`、`parse-extract.png`；提取与保存的剧情页分别使用独立的横向三格漫画 `parse-story-v2.png`、`save-story-v2.png`，画面铺满可用宽度。图片可点开放大；解释统一由小派气泡承接。

删去重复的剧情页后，第3页“先破三塔，再战魔王”以 `battle-rules-comic.png` 双格漫画和两项战场信息串起三塔供能、分队攻塔与魔王决战。第4页保留四格路线与原文字，用 `route-prepare.png`、`route-strategy.png`、`route-towers.png`、`route-boss.png` 作淡化背景，主体在上、下方交错分布。旧剧情页链接转向第3页。

播放器保留步骤、答题、揭晓和进度。战斗支持错误修订、手动出击、暂停、重播、离页停止及减少动态效果。“重置本页”只清当前页；清除三塔状态也会重新锁定魔王。修订采用新的本课存储键，其他课程不变。
