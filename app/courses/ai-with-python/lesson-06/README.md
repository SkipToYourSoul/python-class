# 第六课：决战魔王

数据阶段综合练习。剧情从三塔供能展开：战前准备 → 三队部署 → 攻破全部魔塔 → 三队会合挑战魔王。三个小节、三个课堂练习、一个结课综合演示，共 33 屏。练习包保留三个简短课后填空。

## 三节内容

1. **战前作战准备**：读懂三塔情报；真实 HTTP 获取网页，用 BeautifulSoup 提取整份 CSV 正文并写入 `towers.csv`。36 条记录、8 列，三塔各 12 个时刻（6—17 时），每行包含当班守卫。
2. **部署三队作战策略**：延续第四课方法：望看懂类型与行列，闻用 Python 读取检查，切分组、统计、排序与筛选；问贯穿追问依据。比较各塔外罩、防御均值，筛选外罩低于 30 的记录，再比较守卫防御、查明属性与弱点，部署三队。
3. **用图表攻破三塔**：两图分工 → 折线圈出每塔两个可破罩时段 → 北塔双指标冲突 → 学写两种绘图代码 → 逐塔在散点图上读坐标、比较防御、查弱点并说明方案 → 同屏完整代码填空 → 阵前核验并逐塔出击。图表中的时刻、坐标、候选表与方案共用原始记录，既保留历史证据，也明确阵前新读数。

课后练习分别考查 `requests/csv/write`、`groupby/energy/30`、`hour/energy/hue`，每题三个空，同屏显示，原答案与逐空反馈保留，可修改重试。

课堂练习一集中在第12页，8 个代码填空覆盖导入、获取、解析、定位、提取和写入。核对后保留原填答，可逐空修改、重试和复制当前代码，再到 Notebook 运行并检查 `towers.csv`。原第13页重复的三空练习已删除，第12页后直接进入第二节；课后练习一只保留在练习包中。旧完整代码页和课后三空页链接自动转向第12页。

课堂练习二集中在第20页。左侧为三队部署视频，右侧从上到下为代码和词库。7 空覆盖 `read_csv/info/groupby/mean/count/energy/sort_values`，填满后与练习包内的完整参考逐字一致。旧版进度移除原来的 `head` 空，其余答案和核对结果保留。课后练习二保留在练习包，旧链接转到课堂练习二。

第12、20、29页共用课堂练习版式。左侧播放剧情，右侧依次展示代码、词库、核对按钮和反馈。第29页的 7 空覆盖 `read_csv/lineplot/hour/energy/hue/scatterplot/defense`，保留导入语句并用中文注释提示绘图方法和字段，两条保存语句已经填好。运行后会读取学生自己保存的 CSV，绘制并保存两张作战图。填空答案、复制内容、Notebook 与完整参考共用源字符串，支持逐空反馈、修改重试和状态保留。

第二节第14页漫画按原生横向比例展示，去掉灰色填充。第15页明确分类数据与数值数据，分类卡和第19页三队卡都使用淡化漫画背景。第16页按 `head()`、`info()`、`dtypes` 分步展示：前5条完整8列、36行8列整体信息及每列类型，输出来自真实样本执行生成的 `analysis-evidence.json`。文本类型随Pandas版本可显示 `str` 或 `object`，不能把 `dtypes` 输出末尾的Series类型误当作数据列类型。第16、17页漫画分别推进档案验收、分组比较剧情。

第16页代码从 `INSPECT_CODE` 按步骤累积，只高亮当前讲解的语句；回看前一步、翻页和刷新保留已展示代码，重置本页后重新从 `head()` 开始。输出和小派讲解跟随当前步骤。较矮的投屏视口中，`info()` 与 `dtypes` 采用左代码、右输出布局，腾出漫画区域，保证完整输出与底部讲解不重叠。

第18页候选表沿用 Python `sort_values(["tower", "defense"])` 的结果顺序：塔名按默认字符串顺序为东塔、北塔、西塔，同塔内按防御升序。页面与练习包共用 `windows` 记录，验证时保留其原有顺序，与真实 Pandas 输出逐行比较。

第24页点击揭晓后可直接用左右方向键或 PageUp／PageDown 翻页，返回时保留揭晓状态。共享播放器允许普通按钮获得焦点时使用翻页与目录快捷键；空格、Enter 仍用于按钮自身操作，输入框、图表、滑块与菜单保留各自的键盘交互。

## 数据、策略与剧情门槛

`study-data.ts` 是网页、课件、Python 材料、图表与战斗的共用证据源。外罩严格低于 30 才能突破；之后比较守卫防御并按弱点选择装备。第30屏展示三队领图、核对命令、前往各塔，第31屏再进行阵前核对。三座不同的塔都完成，战役按钮才引导进入魔王视频；重播同塔不累计进度，重置后清空本轮战役进度。

- 北塔炎角兽族：强光；历史计划 11 时，外罩 25、防御 30。10 时外罩虽更低（18），防御却更高（42），不能只看外罩最小值。
- 东塔藤甲魔族：火焰；历史计划 14 时，外罩 22、防御 34。
- 西塔冰翼魔族：热量；历史计划 17 时，外罩 19、防御 25。

历史记录用于解释命令，阵前观测用于判断现在能否出击。第31屏先按作战图与弱点档案核对本队的时刻和装备，通过后才显示阵前新情报。现场外罩低于 30 才能勾选确认并出击。确认框初始不勾选；切塔不沿用上一塔确认，已验证收据仍保留。阵前北、东、西塔外罩/防御分别为 21/32、24/35、22/28。每名当班守卫有唯一编号，统计每塔 `guard.count` 得到 12 条，不重复计数同一守卫。
