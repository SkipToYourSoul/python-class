# 练习包中文字体

本目录包含未修改的 Noto Sans CJK SC Regular 字体，用于显示图中的中文族名、图例与标注。
完整解压练习包并保留本目录即可，无需安装系统字体，也无需联网下载字体。
笔记本的“中文显示环境”单元格和两个完整参考脚本共用相同的加载代码。
