## 战报规则

一行表示一次进攻。`出现的恶魔`中的多个名字用 `/` 分开。记录编号用于辨认事件，不能求平均。
威胁值是哨塔魔力仪记录的每次进攻最高读数，统一为 0—100；数值越大，整场进攻的魔力越强。
它不是某个恶魔的个人伤害。数据中没有“首领”标签。
