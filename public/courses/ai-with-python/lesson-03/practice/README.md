# 第三课：探险家的日记本

电影资料能从文件里读出来，守城情报也能保存下来、交给伙伴继续使用。

## 开始前

1. 使用 Python 3.10 或以上和 JupyterLab。解压整个练习包。
2. 在解压后的 `lesson-03-practice` 文件夹中打开“第三课练习.ipynb”。
3. 第一次使用时，在 Notebook 的准备单元格运行 `%pip install -r requirements.txt`。
4. 按课堂顺序，在空白 Code 单元格亲手输入完整参考代码，再按 Shift + Enter 运行。

安装依赖可能需要联网；安装成功后的文件练习全部离线完成。若提示找不到文件，
先在 JupyterLab 左侧确认 `film_1292052.txt` 和 Notebook 位于同一个文件夹。
本课的相对路径 `./film_1292052.txt` 从程序当前工作文件夹出发；
按上述方式打开 Notebook 时，这里就是练习包文件夹。

## 课堂练习与完成标准

- CHECKLIST 01：在一个代码单元格中完成读取文件、解析 HTML、输出片名、导演、评分和演员；与样本核对一致。
- CHECKLIST 02：在代码中定义 `reports` 列表，把三条情报写入 `handover.txt`，再用 `for line in f` 逐行读取核对。文件与输出都有三条情报，每条一行，没有多余空行。
- CHECKLIST 03：向 AI 提供 `handover.csv`，选择风格并发送创作要求。核对图鉴有三张卡片、资料准确，支持按名称搜索。

## 课后练习与完成标准

- CHECKPOINT 01 · 给下一班勇士留一份档案：编写两条新的冒险记录，保存到新的文件，再重新读取。可以记录补给、任务进度或探险发现。完成标准：一个自己命名的新文件。 两条记录各占一行。 重新读取后的正确输出。在测试副本上再次用 w 打开。先预测旧内容会怎样，再验证。
- CHECKPOINT 02 · 让档案变成你的作品：用自己的情报表，设计一页方便伙伴使用的图鉴。内容与原表一致，样式与布局可以自由设计。作品方向：城堡档案：按名字查阅资料。 冒险手账：展示每次发现。 指挥台：清楚显示地点和弱点。完成标准：与 CSV 逐项一致；没有编造信息；伙伴能看清并找到记录。

电影原始资料是 Notebook 旁的 `film_1292052.txt`、`film_1291546.txt`、`film_1292722.txt`。
这些 `.txt` 文件保存的是 HTML 源码，Python 读取后再用 BeautifulSoup 解析。
`film_1292052.html` 与同名 `.txt` 内容完全相同，供浏览器打开并呈现网页；
直接打开 `.txt` 通常看到的是源码，不会自动呈现为网页。
敌情原始资料在 `samples/`。所有写入代码使用新的输出文件：`handover.txt`、
`handover.csv`、`line-break-test.txt`、`overwrite-test.txt`。它们在运行时生成，不随练习包预先提供。
重复以 `w` 打开同一个已有文件会先清空旧内容，再写入本次内容。
课堂观察覆盖效果使用 `overwrite-test.txt`。课后只在自己文件的测试副本上再次用 `w` 打开，
先预测旧内容会怎样，再验证。保留正式作品和原始样本，不要把输出路径改成它们。

`with` 代码块结束时会关闭文件。`write()` 不会自动换行，所以每条记录后加 `\n`。
`for line in f` 每次取得一行；`readlines()` 会把全部行放进列表，不能用来说明节省内存。
CSV 使用 `csv.DictWriter` 处理字段和分隔符，并在打开文件时设置 `newline=""`。

## 输出对照

`handover.txt` 应有三行：

```text
炎角兽｜北方峡谷｜怕强光
藤甲魔｜迷雾森林｜怕火
冰翼魔｜冰封山口｜怕热
```

`handover.csv` 应有四行：

```csv
恶魔,地点,弱点
炎角兽,北方峡谷,怕强光
藤甲魔,迷雾森林,怕火
冰翼魔,冰封山口,怕热
```

电影样本与出处见 `SOURCES.md`。演员为节选，评分是保存值。本课把电影阅读方法迁移到敌情读写；演员重复计数留作后续数据分析思考。
