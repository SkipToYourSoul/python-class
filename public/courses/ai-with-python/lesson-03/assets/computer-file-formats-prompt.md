## 最终提示词

Use case: scientific-educational.
Create a polished educational illustration for the LEFT HALF of a Chinese classroom lesson about computer files for 10–13 year old children. Landscape 3:2 composition, around 1536x1024 pixels. This must be one coherent illustrated computer, not a webpage UI mockup.
A large friendly desktop computer monitor seen straight-on with a very slight 3D depth, dark navy outline and cobalt-blue casing, small elegant stand and a narrow keyboard at bottom. The monitor and screen fill nearly the whole frame with only 4% margin. Cream paper background #F5F0E6, navy #071A3D, cobalt #1457D9, yellow accents #FFC91C. Clean colorful classroom textbook illustration, soft restrained shading, beautifully crafted folded-corner file sheets. No humans or mascots.
Inside the monitor screen, show EXACTLY EIGHT large file-sheet icons in a clear 2-row by 4-column arrangement. Each file has an immediately recognizable large pictogram above a VERY LARGE readable file extension label. Under each sheet inside screen, print its short Chinese category in large dark navy bold type.
Top row: blue document with text lines, label "DOC", category "文档"; green file with mountain-and-sun photo, label "JPG", category "图片"; purple file with music note, label "MP3", category "音频"; orange file with presentation easel, label "PPT", category "演示文稿".
Bottom row: coral file with filmstrip and play triangle, label "MP4", category "视频"; blue-gray file with plain text lines, label "TXT", category "文本"; red file with a small book/document pictogram (no Adobe logo), label "PDF", category "电子文档"; cobalt file with code angle brackets, label "HTML", category "网页".
The screen is light cream-white. Icons must occupy at least 75% of monitor screen area. Extension labels and category names must be oversized and crisply readable when entire illustration is displayed at 600px wide: use extension letters around 75px and Chinese category letters around 50px in a 1536px wide output. Maintain generous spacing between icons, all eight visible without overlap or clipping.
No title, no paragraph, no explanation labels, no extra text, no logo, no watermark. Do not add folders, arrows, network connections or floating files outside the screen. The sole message: many different kinds of files can be stored in one computer.
